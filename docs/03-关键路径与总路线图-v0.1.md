## 二、⚠️ 关键路径变了

原方案里，关键路径是「备案（5–20 工作日）」。

D7 把真正的起点往前推了一大步：

```
                    ┌─ 公司注册（3–7 工作日）
                    │        │
                    │        ├─→ 商标注册（8–12 个月）← 最长，最该先启动
   今天 ────────────┤        │
                    │        ├─→ ICP 备案（5–20 工作日）─→ 门户才能公开上线
                    │        │
                    │        ├─→ 小程序企业认证（300 元/年）+ 类目资质
                    │        │
                    └────────┴─→ 微信支付商户号（要企业主体）
```

**结论：公司注册是所有事情的总闸门。它很便宜也很快，但没有它，后面一步都动不了。**

同时注意这个**时间差陷阱**：

> 商标办理要 **8–12 个月**，是整条链上最长的一环。
> 如果等门户上线、品牌做出声量了才去申请，被别人抢注或被驳回，你可能被迫改名 —— 前面所有投入白费。
> **所以商标要在拿到营业执照后第一时间提交，而不是等网站做好。**

## 三、各项前置条件详解

### 3.1 公司注册（总闸门）

| 项 | 建议 |
|---|---|
| 类型 | 有限责任公司（一人有限公司亦可） |
| 注册资本 | 认缴制，无需实缴。建议按实际需要填，不必贪大 |
| 时间 | 3–7 个工作日（各地不同） |
| 成本 | 自行办理基本零成本；委托代办通常数百元 |
| 经营范围建议 | 技术开发/技术服务/技术咨询；软件开发；信息系统集成服务；信息技术咨询服务；**设计、制作、代理、发布广告**；企业形象策划；企业管理咨询；市场营销策划；数据处理和存储支持服务；网络技术服务；计算机软硬件及辅助设备零售（若做外贸相关可加货物进出口、技术进出口） |
| 注意 | 经营范围建议一次写全，后续增项要额外跑流程；具体以当地市场监管口径与代办确认为准 |

### 3.2 商标注册

| 项 | 内容 |
|---|---|
| 官费 | **270 元/类**（含 10 个商品/服务项，超出每项 +27 元） |
| 周期 | **8–12 个月**（从申请到拿证） |
| 有效期 | 10 年 |
| 申请主体 | 企业凭营业执照；**自然人需身份证 + 个体工商户营业执照** |
| 建议类别 | **第 35 类**（广告、商业经营、销售服务）—— 最核心<br>**第 42 类**（软件设计开发、技术服务）—— 第二核心<br>可视产品线考虑第 9 类（软件产品，若做可下载软件） |
| 风险动作 | 提交前先检索近似商标；已知存在「杭州商帮帮信息技术有限公司」，需重点排查 |
| 建议 | 尽早提交，拿证前先用 `™`，拿证后才可用 `®` |

### 3.3 ICP 备案

| 项 | 内容 |
|---|---|
| 主体 | 企业备案，需营业执照 + 法人信息 |
| 服务商 | 阿里云（你的 DNS 已在阿里云，链路最顺） |
| 时长 | 阿里云初审 + 管局审核，通常 **5–20 个工作日** |
| 前提 | 需先购买符合备案要求的国内服务器（阿里云 ECS / 轻量应用服务器） |
| 注意 | 网站内容需与备案主体、经营范围相符；备案期间网站不能对外访问 |

### 3.4 小程序（第二期，但资质要提前规划）

| 项 | 内容 |
|---|---|
| 认证 | 企业主体认证约 **300 元/年** |
| 类目 | 涉及电商/交易类目需要相应资质（营业执照、可能涉及食品经营许可等按行业） |
| 支付 | 微信支付商户号需企业主体 |
| 提前量 | 类目与资质审核可能被驳回，第二期开发前就要确认清楚 |

## 四、半年节奏建议（配合 D8「不急」）

| 阶段 | 时间 | 内容 | 关键交付 |
|---|---|---|---|
| **第 0 阶段** | 第 1 周 | 注册公司；确定公司名称与经营范围 | 营业执照 |
| **第 1 阶段** | 第 1–2 周（并行） | 商标检索 + 提交申请；阿里云服务器购买；门户文案定稿 | 商标申请号；门户文案 |
| **第 2 阶段** | 第 2–5 周 | 门户设计与开发（**本地/海外节点预览，不等备案**）；提交 ICP 备案 | 可预览的门户 |
| **第 3 阶段** | 第 5–8 周 | 备案通过 → 正式上线；内容填充；提交搜索引擎收录 | **门户公开上线** |
| **第 4 阶段** | 第 2–4 个月 | 外贸网站通用版 v1（多租户 + 后台 + 询盘 + 多语言框架） | 可交付客户的产品 |
| **第 5 阶段** | 第 4–6 个月 | 小程序通用版 v1；积累第一批种子客户与真实案例 | 第二条产品线 |

**核心原则：开发不等证照。** 门户的设计与开发可以立刻开始，用海外节点或本地预览；证照流程并行推进，谁先完成谁先解锁上线。
