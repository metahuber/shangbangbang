## 一、去哪查

**中国商标网**：https://sbj.cnipa.gov.cn

路径：首页 → 商标查询 → 我接受 → **商标近似查询**

（如果打不开或验证码刷不出来，直接找一家商标代理，让他们免费查一次。代理查这个是标配服务。）

## 二、查什么（按顺序，一共 4 次）

| # | 查询方式 | 输入 | 国际分类 |
|---|---|---|---|
| 1 | 近似查询 | `商帮帮` | **35** |
| 2 | 近似查询 | `商帮帮` | **42** |
| 3 | 近似查询 | `商帮` | 35 |
| 4 | 近似查询 | `商帮` | 42 |

- **35 类** = 广告、商业经营、市场营销（你帮别人卖货做推广）
- **42 类** = 计算机软件设计开发、SaaS（你交付软件和网站）
- 第 3、4 次查「商帮」是为了看有没有近似商标——**两个字相同、一个字不同也可能被判近似**

## 三、怎么看结果

对每一条查到的记录，看三个字段：

| 字段 | 你要看什么 |
|---|---|
| **状态** | 已注册 / 等待实质审查 / 初审公告 / 无效 / 已驳回 |
| **类似群** | 是否和你的业务落在同一类似群（35 类主要看 3501/3502/3503；42 类看 4220） |
| **申请人** | 是谁，是不是那两家公司 |

**重点盯这几个状态**：
- **已注册** → 最大风险，基本不能用
- **初审公告**（3 个月公示期内）→ 你可以提异议，但有成本
- **等待实质审查** → 别人比你早提交，你申请会被驳
- **无效 / 已驳回** → 不构成障碍

## 四、三种结果分别怎么办

### 结果 A：35 类和 42 类都干净
👉 **继续用「商帮帮」**。等公司注册下来第一时间提交申请（270 元/类 × 2 类 = 540 元）。

### 结果 B：某一类被占，另一类干净
👉 仍然可以用，但要知道自己缺哪一块：
- 35 类被占 → 你**不能**用「商帮帮」做广告、推广、代运营服务
- 42 类被占 → 你**不能**用「商帮帮」做软件、网站、SaaS

这种情况下建议：**换一个能两类都注册的字号**，别做半张皮。

### 结果 C：两类都被占
👉 **必须换名**。现在换，成本是改几份文档 + 一个域名；推广之后再换，成本是客户认知。

## 六、时间上的建议

| 时间点 | 动作 |
|---|---|
| **现在**（产品开发期） | 只做检索，确认名字能不能用。**不需要公司** |
| 产品做好之后 | 注册公司（3–7 个工作日） |
| 公司下来后**立刻** | 提交 35 + 42 类商标申请（拿受理号就能用 ™） |
| 拿到受理号后 | 开始推广 |
| 7–12 个月后 | 拿到注册证，才能用 ® |

> ⚠️ 版权和商标是两件事。**公司名核准通过 ≠ 商标能用**，这两套系统互不联通，必须分别确认。
